# CampusTrack Brand Kit

Generated from the supplied CampusTrack logo image.

## Included
- Transparent PNG logo, icon, and wordmark
- Light and dark theme variants
- Preserved SVG exports
- True-vector recreated SVGs
- favicon.ico + PNG/SVG favicon set
- Apple touch icon
- PWA 192px and 512px icons
- site.webmanifest
- Web CSS theme tokens
- Android launcher icons (mdpi–xxxhdpi)
- Android adaptive icon resources
- Android light/dark colors.xml
- HTML brand guide

## Important
The source logo was raster artwork. `*-preserved.svg` files preserve the original supplied appearance inside an SVG container. `*-vector-recreated.svg` files are true-vector recreations and may differ slightly in typography/geometry.

## Core palette
- Campus Navy: #182632
- Deep Navy: #0E1822
- Track Teal: #2DB893
- Off White: #F7FAF9
- Muted Gray: #66727C
